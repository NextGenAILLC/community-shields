# Security Policy

## About this site

Community Shields is a static informational website. It collects expressions of
interest through a contact form and does not operate user accounts, payments,
or an emergency service. For emergencies, call 911.

## Reporting a vulnerability

If you believe you have found a security issue with this website or this
repository, please report it privately so it can be fixed before it is
discussed publicly:

- Preferred: use GitHub's private vulnerability reporting for this repository:
  https://github.com/NextGenAILLC/community-shields/security/advisories/new
- Or email: hello@nextgenerationai360.com with "Security" in the subject line.

Please include what you found, the page or file involved, and the steps to
reproduce it if you can. Do not include anyone else's personal information.

## What to expect

This is a small, independently run project. Reports are read and taken
seriously, and confirmed issues will be fixed as promptly as practical.
Please allow a reasonable window for a fix before any public disclosure.

Thank you for helping keep visitors safe.
